# basalt-plugin-semantic-facts-csharp

Semantic facts provider for C#. 

Consumes parser-derived information to provide high-level semantic facts such as Call Hierarchy and Symbol Declarations.

## Provides
- `semantic-facts@csharp/v1`

## Requires
- `parse.call-sites@csharp/v1`
- `parse.retrieval@csharp/v1`
